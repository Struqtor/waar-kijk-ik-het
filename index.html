Eenmalig instellen

De gegevens komen van TMDB, een open filmdatabank die de streaminggegevens van JustWatch doorgeeft. Daarvoor heb je een gratis, persoonlijke sleutel nodig.

  1. Maak een gratis account op themoviedb.org.
  2. Open Instellingen › API en vraag een sleutel aan voor persoonlijk gebruik.
  3. Kopieer het API Read Access Token (de lange sleutel) en plak het hieronder.

De sleutel blijft in deze browser en gaat alleen naar api.themoviedb.org. Hij geeft enkel leestoegang.

Bewaar de sleutel in je wachtwoordbeheerder, zoals 1Password, met het adres van deze site als website. Dan vul je hem op elk toestel met één tik in.
